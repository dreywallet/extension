# Drey 0.14.14 Store notes

Transaction approvals are now easier to review on both compact and expanded
layouts. The request summary stays clear while the approval actions remain
easy to reach, including for longer marketplace reviews and narrower windows.

This update also improves spacing and responsive behavior so important review
details do not feel crowded or leave confusing empty areas.

## Release check

- Confirm the extension identifies itself as version 0.14.14.
- Confirm approval actions remain visible while reviewing a long request.
- Confirm compact, narrow, and expanded approval layouts remain readable.
- Confirm blocked requests have no Sign action.
