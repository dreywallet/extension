# Drey 0.17.0 Store notes

## What's new

Drey beta 0.17.0 makes everyday screens shorter and calmer. In Send, the
next step stays in view, the network fee is one line you can open to
change, and the review shows how much you are sending, to whom, the fee and
the total in one card, with the address in easy-to-check groups of four.
Receive puts Copy right under your address and tucks the optional amount
request away. Settings is grouped and easier to scan, the full page shows
the same header as the popup, and recovery phrase entry completes words and
accepts pasted phrases.

This update adds no browser permissions.
