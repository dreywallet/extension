# Drey 0.14.9 Store notes

## What's new

This release makes multi-wallet use simpler and keeps recovery guidance visible
without blocking normal wallet use.

## Reviewer focus

- Unlock once to use and switch between wallets linked to the same app password.
- New wallets can be used after acknowledging a deferred recovery backup, with a
  persistent reminder until the backup is verified.
- Wallet switching returns to the selected wallet's home screen with its current
  account name and freshly loaded status.
- Community Vault is now clearly described and grouped under Advanced settings.
- Receive, send, activity, website approval, and existing recovery flows remain
  available for created and restored wallets.
